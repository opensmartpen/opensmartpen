# Contributing

Bug reports and ideas are welcome. Open an issue.

## Code

- Open an issue before you write code, so we can agree on the change.
- Your contribution is licensed under Apache-2.0, the license of this repository.
- A contributor agreement is necessary before the first merge. It lets the copyright holder change the license of the project later. The agreement is not ready yet; until it is, a pull request from outside the project stays open.

## Build and test

The app is in `app/`. From there: `swift build`, `swift test`. The tests need no network and no pen. `app/README.md` has the details.
